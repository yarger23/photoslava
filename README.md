# Photoslava

Восстановленная публичная версия photoslava.com с обновлённым дизайном. 16 страниц, текущие фотографии, существующие URL, заголовки и метаданные. Код сайта хранится здесь; публикация выполняется на собственном VPS, не на GitHub Pages.

## Главная 3.1

Первый экран разделён на текст и фотографию. Все четыре серии видны в открытой сетке, направления оформлены компактными строками, тарифы — без повторяющихся обложек. Хэдер сохраняет оформление действующего сайта. Изображения получают версию в URL, чтобы не оставаться в кеше после исправления файла.

## Что изменилось

- Читаемое меню, подписи и текст; согласованные отступы и размеры заголовков.
- Кнопки портфолио и записи на первом экране.
- Компактные обложки портфолио, цен, статей и контактов.
- Тарифы с отдельным количеством фотографий и выровненными кнопками.
- Три шага съёмки вместо большого повторяющегося абзаца.
- Фотографии выше текстового описания на страницах направлений.
- Адаптация для телефона, планшета и компьютера; меню с Escape, управлением фокусом и блокировкой фона.
- Telegram вместо WhatsApp. В форме посетитель составляет черновик; кнопка открывает чат с фотографом. Посетитель самостоятельно отправляет сообщение в Telegram.

Серверный PHP-код, административная панель и база заявок старой версии не доступны из публичного HTML и не восстановлены. Новая публичная версия — статический сайт; ей не нужны PHP, Node, БД или секреты. Старые серверные файлы скрипт не удаляет и не архивирует. Чужие домены, SSL-сертификаты и их настройки не меняются.

## Первая публикация

На компьютере подключитесь к VPS:

```sh
ssh root@31.177.83.112
```

В терминале VPS:

```sh
git clone git@github.com:yarger23/photoslava.git /opt/photoslava-source
cd /opt/photoslava-source
bash scripts/deploy.sh
```

Репозиторий приватный: SSH-ключ сервера должен иметь доступ к `yarger23/photoslava`. Если clone сообщает `Permission denied (publickey)`, сначала предоставьте существующему ключу сервера доступ к репозиторию в GitHub. Скрипт не меняет ключи и разрешения автоматически. Не вставляйте токены в команду или URL.

## Все последующие обновления

В терминале VPS одна команда:

```sh
cd /opt/photoslava-source && bash scripts/deploy.sh
```

Обновление требует `git`, Python 3.9+, Nginx и systemd. Используется `git pull --ff-only`: локальные изменения или другая ветка останавливают обновление, не уничтожаются.

### Как работает публикация

1. Читает `/etc/nginx/sites-enabled/photoslava.com` и распознаёт только server-блоки Photoslava.
2. Находит существующий document root: `/var/www/photoslava` или `/var/www/photoslava/public`. При другой структуре останавливается и сообщает причину.
3. Собирает сайт и проверяет все ссылки и ресурсы.
4. Устанавливает `index index.html` и статическую маршрутизацию в `location /` только у Photoslava. SSL и HTTP→HTTPS остаются прежними.
5. Проверяет `nginx -t`, заменяет файлы по одному атомарно и вызывает `systemctl reload nginx`.

**Резервных копий, архивов и каталогов старых релизов не создаёт — по указанию владельца.** Если проверка конфигурации завершается ошибкой, прежний текст конфигурации возвращается из памяти. Для содержимого сайта автоматического отката нет. Файлы других сайтов, прежние загрузки и базы не удаляются. При нестандартной конфигурации публикация прекращается; не обходите эту проверку без просмотра vhost.

Это подготовленный и протестированный на примерах скрипт, не подтверждение выполнения на VPS. Доступа к серверу при подготовке не было. После первого запуска откройте главную, `/services`, `/portfolio`, `/contacts` и проверьте их на телефоне и компьютере. Визуальная проверка новой версии в облачном браузере до публикации не выполнена: локальный предпросмотр недоступен из его окружения.

## Редактирование

| Файлы | Назначение |
| --- | --- |
| `source/pages/*.html` | Содержимое 16 страниц |
| `source/components/` | Общие шапка, подвал и форма контакта |
| `source/routes.json` | URL страниц |
| `public/assets/css/base.css` | Восстановленные базовые стили |
| `public/assets/css/design.css` | Все изменения дизайна и адаптивности |
| `public/assets/js/site.js` | Меню, слайдер, выбор тарифа, Telegram |
| `public/uploads/seed/optimized/` | Текущие фотографии в WebP, без внешней зависимости от старого сайта |
| `site.json` | Адрес сайта, Telegram и необязательная ссылка MAX |

MAX пока скрыт. Чтобы добавить его, укажите полную HTTPS-ссылку вашего профиля `max.ru` в поле `max` файла `site.json` и опубликуйте обновление. Поле должно оставаться пустым, пока точная ссылка не известна. Ссылка не выводится как неработающая кнопка.

## Локальная сборка и проверки

```sh
python3 scripts/build.py
python3 scripts/check.py
python3 -m unittest discover -s tests -v
node --check public/assets/js/site.js  # необязательно, при наличии Node
python3 scripts/preview.py            # http://127.0.0.1:8765
```

`dist/` создаётся при сборке, в Git не хранится. Python-сборка не требует сторонних библиотек. Фотографии сохраняют текущие сюжеты; 1920px WebP-файл `outdoor-blue` восстановлен из оригинального JPG, поскольку исходный WebP возвращал пустой файл.

Telegram-черновики используют официальный формат `https://t.me/username?text=...`: https://core.telegram.org/api/links#public-username-links . Форма не сообщает об отправке заявки и не сохраняет персональные данные на сервере.
